# AI-SDLC Accelerator — Live Demo

A single, self-contained HTML page (no build step, no dependencies) that replays a real session of the [AI-SDLC Accelerator](https://github.com/UmaRamanathan-DA/ai-sdlc-accelerator)'s CLI: guardrails redacting planted secrets, then two Claude models reviewing the same file side by side with real cost/latency/token counts.

It's a recorded replay, not a live API call — a static public page can't safely hold an API key. The source project (private, in active development) generates the data this page replays.

Published via GitHub Pages from this repo's `main` branch. Part of [Uma Ramanathan's portfolio](https://umaramanathan-da.github.io/portfolio/).
